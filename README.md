## 📚 Course Curriculum

### 🟢 Phase 1: Core Concepts & Setup

#### **1. Getting Started**

*Introduction to the course, the Terraform workflow (Init, Plan, Apply, Destroy), and what you will achieve by the end of this journey.*

#### **2. Why Infrastructure as Code (IaC)?**

*The evolution from manual server provisioning to automated, version-controlled infrastructure.*

#### **3. Why Terraform?**

*Understanding Terraform's declarative language, state management, and multi-cloud advantages over vendor-locked tools.*

#### **4. Install and Configure Terraform**

*Step-by-step setup guides for Windows, macOS, and Linux, including IDE integration and CLI authentication.*

---

### 🔵 Phase 2: Terraform Deep Dive

#### **5. Terraform Common Topics**

*Master the foundational building blocks of HashiCorp Configuration Language (HCL).*

* **Variables:** Making your configurations dynamic and reusable.
* **Modules:** Abstracting complex infrastructure into simple, callable packages.
* **Outputs:** Extracting critical deployment data (like IP addresses) after provisioning.
* **State File:** Understanding `terraform.tfstate`, remote backends, and state locking.
* **Providers:** Connecting Terraform to external APIs (AWS, Azure, GCP, GitHub, etc.).
* **Provisioners:** Executing scripts on a local or remote machine as part of resource creation.

---

### 🟠 Phase 3: Cloud Provider Projects

#### **6. Terraform and AWS**

*Deploying infrastructure on Amazon Web Services.*

* **A. Configure AWS Credentials:** Setting up IAM users and the AWS CLI for secure authentication.
* **B. AWS Projects:**
1. **EC2:** Provisioning and bootstrapping virtual machines.
2. **VPC:** Building a secure, custom Virtual Private Cloud networking environment.
3. **S3:** Creating and managing secure object storage buckets.
4. **3-Tier Application:** Architecting a complete web, application, and database stack.



#### **7. Terraform and Azure**

*Deploying infrastructure on Microsoft Azure.*

* **A. Configure Azure Credentials:** Authenticating via the Azure CLI and Service Principals.
* **B. Azure Projects:**
1. **VM:** Deploying Windows and Linux Virtual Machines.
2. **VNET and Subnets:** Configuring Azure Virtual Networks and routing.
3. **Blob and Storage Options:** Managing Azure Storage Accounts and Blob containers.
4. **3-Tier Application:** Building a highly available, multi-tier architecture on Azure.



#### **8. Terraform and GCP**

*Deploying infrastructure on Google Cloud Platform.*

* **A. Configure GCP Credentials:** Setting up Service Accounts and JSON keys.
* **B. GCP Projects:** *(Upcoming projects covering Compute Engine, VPC Networks, and Cloud Storage)*
